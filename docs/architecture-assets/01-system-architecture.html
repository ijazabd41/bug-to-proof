Generation path

1Discover trusted page context from configured source.
2Send sanitized report and inventory to the provider.
3Validate every action and target before compilation.
4Execute only the deterministic compiled test.

Verification path

1Freeze a human-approved failing reproduction.
2Apply an approved patch in an isolated workspace.
3Run the identical test plus regression gates.
4Export independently checkable proof.
